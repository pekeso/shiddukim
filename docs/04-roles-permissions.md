# Roles and Permissions

## Roles

### SUPER_ADMIN
Can manage the whole platform.

### CHURCH_ADMIN
Can manage church configuration, users, communities, reports.

### SECRETARY
Can register members, update basic member records, create appointments.

### PASTOR
Can review marriage requests, add pastoral notes, classify cases, approve medical referral.

### COMMUNITY_LEADER
Can view members in assigned community and help with verification.

### MEMBER
Can view own profile, activate account, submit marriage request, book appointments.
