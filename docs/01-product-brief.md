# Product Brief

The platform helps the church register official members, generate unique member codes, activate member accounts, manage marriage requests, schedule pastoral appointments, generate documents, and later integrate affiliated hospitals.

The MVP focuses on:
- member registration by church admins
- member account activation using member code and OTP
- marriage request submission
- pastor review
- green/orange/red case classification
- appointment management
- document generation
- professional dashboard for pastors and church admins
