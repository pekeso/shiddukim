# UI Guidelines

## Language
All UI labels must be in French.

## Brand Identity
Use the church logo provided in `/public/brand/logo.jpeg`.

## Suggested Colors
Inspired by the logo:
- Deep Blue: #003B8E
- Royal Blue: #0057B8
- Gold: #F2B705
- White: #FFFFFF
- Light Gray: #F5F7FA
- Dark Text: #1F2937
- Danger Red: #B91C1C
- Success Green: #15803D
- Warning Orange: #F97316

## UI Style
- Clean institutional design
- Professional church administration feel
- Avoid playful startup look
- Use cards, tables, dashboards, and clear workflows
- Admin portal should feel serious, trustworthy, and simple

## French Menu Labels
- Tableau de bord

- Communautés
